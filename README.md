---

# 📌 Project Overview

The **Insurance Analytics Dashboard** is an end-to-end Data Analytics project developed to analyze insurance policy data and generate meaningful business insights using Microsoft Excel, MySQL, Power BI, and Tableau.

The project demonstrates the complete analytics lifecycle, including data cleaning, SQL analysis, KPI generation, dashboard development, and business intelligence reporting. The dashboards provide insights into customer demographics, policy performance, claim analysis, premium trends, and overall business performance.

---

# 🎯 Project Objectives

- Analyze customer and policy data to identify business trends.
- Monitor insurance claims and premium performance.
- Generate business KPIs for decision-making.
- Perform SQL-based business analysis using MySQL.
- Build interactive dashboards using Excel, Power BI, and Tableau.
- Present insights through effective data visualization.
